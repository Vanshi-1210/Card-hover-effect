# Profile Cards with Hover Effect 🎴

A minimalist and interactive profile card layout built using HTML5 and CSS3. 

## 🚀 Features
* **Hover Animation:** Cards lift up smoothly (`translateY`) and cast a deeper shadow when hovered.
* **Responsive Row:** Cards align perfectly side-by-side using `inline-block` layout rules.
* **Proportional Scaling:** Image containers utilize modern aspect-ratio clipping to prevent avatar stretching.
* **Clean Typography:** Structured typography with proper padding rules inside text descriptions.

---

## 🛠️ Tech Stack Used
* **HTML5** - For semantic markup structure.
* **CSS3** - For custom properties, transition effects, and modern box-shadow layouts.
